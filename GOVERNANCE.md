# Governance

The maintainer reviews changes, manages releases, and handles private security
reports. Contributors can propose changes and discuss them in GitHub issues
and pull requests. [Contributing](CONTRIBUTING.md)

Record decisions that affect public contracts or cloud resource ownership in
an [architecture decision record](docs/adr/README.md). The maintainer makes
the final decision and records the reason. Coordinate security fixes privately
until disclosure. [Security policy](SECURITY.md)

Releases come from protected `main` and use signed artifacts and semantic
versions. [Publishing](docs/publishing.md)
