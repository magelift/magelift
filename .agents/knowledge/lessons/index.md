# lessons

## Concepts

* [Autopilot GMP collectors use gke-gmp-system](Autopilot%20GMP%20collectors%20use%20gke-gmp-system.md) - GKE Autopilot managed Prometheus collectors are a DaemonSet named collector in gke-gmp-system, not gmp-system.
* [AWS failed resume must not delete Pulumi state while the stack lives](AWS%20failed%20resume%20must%20not%20delete%20Pulumi%20state%20while%20the%20stack%20lives.md) - Harness EXIT deleted the awf18 S3 state bucket after resume fingerprint mismatch, leaving a billed Magento stack with no Pulumi state.
* [AWS Name attributes need explicit truncation](AWS%20Name%20attributes%20need%20explicit%20truncation.md) - Pulumi auto-names and Magelift stack prefixes like acceptance-preview-* overflow AWS limits (ALB/TG 32, AOSS VPC endpoint 32, AOSS collection/group Magelift regex max 26).
* [Bootstrap must not adopt an existing KMS alias by name alone](Bootstrap%20must%20not%20adopt%20an%20existing%20KMS%20alias%20by%20name%20alone.md) - An expected MageLift KMS alias can already resolve to a manually managed or unrelated key.
* [Cloud Armor GA import drops requestBodiesToExclude](Cloud%20Armor%20GA%20import%20drops%20requestBodiesToExclude.md) - Magento-safe Armor needs request-body exclusions; Compute v1 import stores GraphQL parsing and 64 KB inspection but not requestBodiesToExclude (beta REST only).
* [CloudFront CachingDisabled policy constraints 2026-07-19](CloudFront%20CachingDisabled%20policy%20constraints%202026-07-19.md) - Custom CloudFront cache policies with Min/Default/Max TTL all 0 (caching disabled) reject CookieBehavior/QueryStringBehavior other than none and reject EnableAcceptEncodingGzip/Brotli true.
* [CloudFront origin groups reject write methods on the default cache behavior](CloudFront%20origin%20groups%20reject%20write%20methods%20on%20the%20default%20cache%20behavior.md) - AWS CreateDistribution rejects origin-group default cache behaviors that allow POST/PUT/PATCH/DELETE; GET/HEAD/OPTIONS is the live contract.
* [Cosign identity-token files must be a single-line JWT](Cosign%20identity-token%20files%20must%20be%20a%20single-line%20JWT.md) - A trailing newline in a Cosign --identity-token file makes Fulcio reject the Authorization header; strip CR/LF before signing.
* [Default vendor WAF rulesets are not Magento-safe](Default%20vendor%20WAF%20rulesets%20are%20not%20Magento-safe.md) - Magento 2 needs count-overrides and 64 KB body inspection; unmodified AWS CommonRuleSet, Cloud Armor sensitivity 4, and generic CRS PL2+ block admin WYSIWYG, uploads, and GraphQL.
* [Do not rematerialize magelift destroy after orphan secret delete](Do%20not%20rematerialize%20magelift%20destroy%20after%20orphan%20secret%20delete.md) - After force-clean deletes Magento secrets, a later magelift destroy previews CREATE of Cloud SQL instead of finishing teardown.
* [ECS integrated ALB must target varnish container 2026-07-19](ECS%20integrated%20ALB%20must%20target%20varnish%20container%202026-07-19.md) - For applicationMode=integrated, ECS Service LoadBalancers.ContainerName must be varnish (port 6081), not web.
* [EXIT traps cannot be the cleanup authority](EXIT%20traps%20cannot%20be%20the%20cleanup%20authority.md) - Record owned resources in a restartable ledger before provider create; traps disappear on kill, crash, or sleep.
* [Fargate Varnish VSM must use -n /tmp not /dev/shm](Fargate%20Varnish%20VSM%20must%20use%20-n%20-tmp%20not%20-dev-shm.md) - From magento-aws-stack / a prior shop: Varnish VSM default can land on Fargate /dev/shm (64 MiB, sharedMemorySize unsupported).
* [GCP acceptance force_clean must wait for producer deletes before PSA teardown](GCP%20acceptance%20force_clean%20must%20wait%20for%20producer%20deletes%20before%20PSA%20teardown.md) - force_clean_orphans issues async deletes for GKE, Cloud SQL, Memorystore, and SCP.
* [GCP Autopilot destroy after one hour uses DELETE_UNREACHABLE](GCP%20Autopilot%20destroy%20after%20one%20hour%20uses%20DELETE_UNREACHABLE.md) - Stack kubeconfig is a static OAuth token from apply. After ~1h Pulumi k8s destroy fails credentials while gcloud kubectl still works. Set PULUMI_K8S_DELETE_UNREACHABLE=true so GKE cluster delete via GCP API wipes workloads.
* [GCP Cloud SQL MySQL 8.4 import needs trusted function creators](GCP%20Cloud%20SQL%20MySQL%208.4%20import%20needs%20trusted%20function%20creators%202026-08-07.md) - Magento dumps with stored functions fail on binary-logged Cloud SQL MySQL unless log_bin_trust_function_creators is enabled.
* [GCP Magento candidate health needs LoadBalancer base_url](GCP%20Magento%20candidate%20health%20needs%20LoadBalancer%20base_url.md) - Seed dumps keep Magento base_url on localhost; CheckRuntime treats a LoadBalancer 302 to localhost as unhealthy until config:set + cache:flush.
* [GCP Magento destroy must pass --destroy-backups](GCP%20Magento%20destroy%20must%20pass%20--destroy-backups.md) - Pulumi destroy leaves Cloud SQL FINAL backups; magelift destroy without --destroy-backups is not leftover-deletion evidence.
* [GCP Memorystore Valkey requires Service Connection Policy](GCP%20Memorystore%20Valkey%20requires%20Service%20Connection%20Policy.md) - Memorystore for Valkey DesiredAutoCreatedEndpoints (PSC service connectivity automation) fails with "No service connection policy is associated with project/network/region" unless a networkconnecti...
* [GCP native edge managed certs wait on DNS and 443 not port 80](GCP%20native%20edge%20managed%20certs%20wait%20on%20DNS%20and%20443%20not%20port%2080.md) - Native Cloud CDN edge is HTTPS-only, so curl to :80 is empty. Keep Cloudflare DNS-only, treat FAILED_NOT_VISIBLE as retryable, and wait up to 3600s after public DNS matches the forwarding IP.
* [GCP PSA teardown needs removePeering after Cloud SQL soft-delete lag](GCP%20PSA%20teardown%20needs%20removePeering%20after%20Cloud%20SQL%20soft-delete%20lag.md) - After Cloud SQL delete, servicenetworking Connection delete often fails with FLOW_SN_DC_RESOURCE_PREVENTING_DELETE_CONNECTION (producer still listed briefly).
* [GCP regional Cloud SQL MySQL requires binary logging](GCP%20regional%20Cloud%20SQL%20MySQL%20requires%20binary%20logging%202026-08-05.md) - Regional Cloud SQL for MySQL creation fails unless binary logging is enabled.
* [GKE Autopilot Cloud Logging components are SYSTEM_COMPONENTS and WORKLOADS](GKE%20Autopilot%20Cloud%20Logging%20components%20are%20SYSTEM_COMPONENTS%20and%20WORKLOADS.md) - Autopilot create-auto enables SYSTEM_COMPONENTS and WORKLOADS, not the obsolete SYSTEM and WORKLOAD enum values.
* [GKE Autopilot cluster name max 40 characters](GKE%20Autopilot%20cluster%20name%20max%2040%20characters.md) - gcp.container.Cluster name cannot exceed 40 characters.
* [GKE Pulumi k8s provider must not require gke-gcloud-auth-plugin](GKE%20Pulumi%20k8s%20provider%20must%20not%20require%20gke-gcloud-auth-plugin.md) - Pulumi kubernetes provider against GKE Autopilot failed with gke-gcloud-auth-plugin not found when kubeconfig used exec auth.
* [Google-managed SSL certificates can take longer than 20 minutes](Google-managed%20SSL%20certificates%20can%20take%20longer%20than%2020%20minutes.md) - A Google-managed cert stays PROVISIONING until public DNS points at the forwarding IP; twenty minutes after the A record is not a TLS failure.
* [MAGELIFT_KUBECONFIG must match the current GKE cluster](MAGELIFT_KUBECONFIG%20must%20match%20the%20current%20GKE%20cluster.md) - Inherited gcloud kubeconfig from a previous KEEP can reuse the GKE public IP with a stale CA and fail day2:logs as x509 unknown authority.
* [Magento 2.4.6 rejects MySQL 8.4](Magento%202.4.6%20rejects%20MySQL%208.4%202026-08-06.md) - The 2.4.6-p15 image rejected MySQL 8.4 during installation and completed with MySQL 8.0.
* [Magento deploy writes env.php before traffic moves](Magento%20deploy%20writes%20env.php%20before%20traffic%20moves.md) - A one-shot deploy task generates env.php, checks the database, and runs setup:upgrade. Serving rolls only if that task exits 0. The crypt key is a one-time random.
* [Magento image builds must not see a runtime env.php](Magento%20image%20builds%20must%20not%20see%20a%20runtime%20env.php.md) - DI compile and static content run in a CLI builder with no database. The runtime env.php and its auto-prepend stay on the serving image. The builder upgrades Debian packages before installing git, because that image is scanned on its own.
* [nginx readonly rootfs needs /var/log/nginx tmpfs](nginx%20readonly%20rootfs%20needs%20-var-log-nginx%20tmpfs.md) - nginx opens /var/log/nginx/error.log before applying nginx.conf error_log /dev/stderr.
* [OCI republish does not copy Sigstore signatures](OCI%20republish%20does%20not%20copy%20Sigstore%20signatures.md) - Pushing the same image digest to a new ECR or Artifact Registry repository does not copy Cosign/Rekor signatures; magelift promote then fails with no signatures found.
* [RDS ManageMasterUserPassword secret only has username password](RDS%20ManageMasterUserPassword%20secret%20only%20has%20username%20password.md) - AWS RDS/Aurora ManageMasterUserPassword secrets contain only username and password JSON keys, not host, port, or dbname.
* [Rollback copies promote signatures and Magento schema epoch](Rollback%20copies%20promote%20signatures%20and%20Magento%20schema%20epoch.md) - Deploy journal rows are often unsigned and epoch-less; rollback must look up Cosign metadata and schemaEpoch from the newest promote of the same digest, and production must observe Magento patch_list plus setup_module or fail closed.
* [Stale Pulumi DIY locks after killed magelift deploy](Stale%20Pulumi%20DIY%20locks%20after%20killed%20magelift%20deploy.md) - Killing magelift mid-update leaves S3 DIY locks under .pulumi/locks/ and Magelift deploy lock.
* [Unsigned provider lock entries are refused before exec](Unsigned%20provider%20lock%20entries%20are%20refused%20before%20exec.md) - magelift.providers.lock requires a sha256 digest plus Cosign identity and issuer. VerifyLocal hashes the binary and checks the Cosign blob before any go-plugin spawn. plugin.Open is forbidden.
