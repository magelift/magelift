## Concepts

* [Acceptance harness seed image defaults must expand](Acceptance%20harness%20seed%20image%20defaults%20must%20expand.md) - Escaped ${VAR:-default} in aws-acceptance-local.sh made kubectl run receive a literal invalid image name.
* [Acceptance JSONL PASS needs reuse-boundary identities](Acceptance%20JSONL%20PASS%20needs%20reuse-boundary%20identities.md) - Unsealed Magento catalog PASS becomes SKIP unless the harness exports fixture, backup, observability, edge, schema, migration, state backend, and checkpoint fingerprint; dry-run PASS must stay SKIP.
* [Acceptance shell checks must run under Bash](Acceptance%20shell%20checks%20must%20run%20under%20Bash%202026-08-04.md) - MageLift acceptance scripts use Bash semantics and ad hoc checks must avoid zsh reserved variables.
* [ACM DomainValidationOptions JSON can exist before ResourceRecord](ACM%20DomainValidationOptions%20JSON%20can%20exist%20before%20ResourceRecord.md) - A non-null DomainValidationOptions array is not enough to publish CNAMEs; wait until every option has ResourceRecord.Name and Value.
* [Act go-verify lint typecheck can be SIGKILL](Act%20go-verify%20lint%20typecheck%20can%20be%20SIGKILL.md) _(env macos)_ - Local `act -j go-verify` pulls lint (`./...`); golangci typecheck of pulumi-gcp can SIGKILL in Colima when disk/RAM are tight; leftover act containers keep gigabytes.
* [ALB target port must match web security rules](ALB%20target%20port%20must%20match%20web%20security%20rules.md) - The ingress target group and ECS container use port 8080.
* [AOSS collection-group OCU rule is undocumented by AWS](AOSS%20collection-group%20OCU%20rule%20is%20undocumented%20by%20AWS.md) - MageLift's serverless OCU step rule is empirically observed, not published by AWS — do not relax the validator against the docs.
* [AOSS collection-group OCU values cannot be zero](AOSS%20collection-group%20OCU%20values%20cannot%20be%20zero.md) - CreateCollectionGroup rejects minIndexingCapacityInOCU=0.
* [Autopilot GMP collectors use gke-gmp-system](Autopilot%20GMP%20collectors%20use%20gke-gmp-system.md) - GKE Autopilot managed Prometheus collectors are a DaemonSet named collector in gke-gmp-system, not gmp-system.
* [AWS failed resume must not delete Pulumi state while the stack lives](AWS%20failed%20resume%20must%20not%20delete%20Pulumi%20state%20while%20the%20stack%20lives.md) - Harness EXIT deleted the awf18 S3 state bucket after resume fingerprint mismatch, leaving a billed Magento stack with no Pulumi state.
* [AWS free plan blocks Aurora MySQL 2026-07-19](AWS%20free%20plan%20blocks%20Aurora%20MySQL%202026-07-19.md) - Free plan AWS accounts reject CreateDBCluster for aurora-mysql (FreeTierRestrictionError); only aurora-postgresql allowed.
* [AWS live acceptance traps](AWS%20live%20acceptance%20traps.md) - AWS live acceptance fails first on bootstrap-before-harness, base64 cache secrets, VPC OpenSearch admission, and blank amazon-mq instance type.
* [AWS Magento wiring follows a prior shop](AWS%20Magento%20wiring%20follows%20a%20prior%20shop.md) - A prior private Magento-on-AWS shop is one field example. It is not the only architecture and it does not certify MageLift cells.
* [AWS Name attributes need explicit truncation](AWS%20Name%20attributes%20need%20explicit%20truncation.md) - Pulumi auto-names and Magelift stack prefixes like acceptance-preview-* overflow AWS limits (ALB/TG 32, AOSS VPC endpoint 32, AOSS collection/group Magelift regex max 26).
* [AWS WAFv2 AssociationConfig RequestBody keys are resource-type enums](AWS%20WAFv2%20AssociationConfig%20RequestBody%20keys%20are%20resource-type%20enums.md) - create-web-acl AssociationConfig.RequestBody map keys must be CLOUDFRONT, not CloudFront; the live 20260813v Magento-safe WAF cell failed ValidationException before the WebACL existed.
* [Bootstrap must not adopt an existing KMS alias by name alone](Bootstrap%20must%20not%20adopt%20an%20existing%20KMS%20alias%20by%20name%20alone.md) - An expected MageLift KMS alias can already resolve to a manually managed or unrelated key.
* [CI bake --load needs single platform and disabled attestations](CI%20bake%20--load%20needs%20single%20platform%20and%20disabled%20attestations.md) - Supported bake targets set platforms amd64+arm64 plus SBOM/provenance attestations.
* [Cleanup ledger run IDs must be unique across providers](Cleanup%20ledger%20run%20IDs%20must%20be%20unique%20across%20providers.md) - Reconcile scans the whole `.magelift/cleanup` directory; reusing a run ID or duplicating claimed identities blocks the next provider cell before it mutates.
* [Cloud Armor GA import drops requestBodiesToExclude](Cloud%20Armor%20GA%20import%20drops%20requestBodiesToExclude.md) - Magento-safe Armor needs request-body exclusions; Compute v1 import stores GraphQL parsing and 64 KB inspection but not requestBodiesToExclude (beta REST only).
* [Cloud email uses secret references not credentialEnv](Cloud%20email%20uses%20secret%20references%20not%20credentialEnv.md) - Cloud `email.credential` is a provider-matching secret reference; `local.email.credentialEnv` is workstation-only. Resolve success is not certified SES delivery.
* [Cloudflare DNS helpers need init before cleanup](Cloudflare%20DNS%20helpers%20need%20init%20before%20cleanup.md) - Sourcing lib-cloudflare-dns.sh does not set CLOUDFLARE_ACCEPTANCE_ZONE; call cloudflare_acceptance_dns_init first or set -u aborts cleanup.
* [CloudFront CachingDisabled policy constraints 2026-07-19](CloudFront%20CachingDisabled%20policy%20constraints%202026-07-19.md) - Custom CloudFront cache policies with Min/Default/Max TTL all 0 (caching disabled) reject CookieBehavior/QueryStringBehavior other than none and reject EnableAcceptEncodingGzip/Brotli true.
* [CloudFront origin groups reject write methods on the default cache behavior](CloudFront%20origin%20groups%20reject%20write%20methods%20on%20the%20default%20cache%20behavior.md) - AWS CreateDistribution rejects origin-group default cache behaviors that allow POST/PUT/PATCH/DELETE; GET/HEAD/OPTIONS is the live contract.
* [Cosign identity-token files must be a single-line JWT](Cosign%20identity-token%20files%20must%20be%20a%20single-line%20JWT.md) - A trailing newline in a Cosign --identity-token file makes Fulcio reject the Authorization header; strip CR/LF before signing.
* [Cosign signing identity is Sigstore OIDC not the Magento cloud provider](Cosign%20signing%20identity%20is%20Sigstore%20OIDC%20not%20the%20Magento%20cloud%20provider.md) - magelift sign and promote discover the current gcloud or CI login; Cosign flags are advanced. Cloud-native image signatures are not a substitute.
* [Default vendor WAF rulesets are not Magento-safe](Default%20vendor%20WAF%20rulesets%20are%20not%20Magento-safe.md) - Magento 2 needs count-overrides and 64 KB body inspection; unmodified AWS CommonRuleSet, Cloud Armor sensitivity 4, and generic CRS PL2+ block admin WYSIWYG, uploads, and GraphQL.
* [Do not rebuild bundled PHP 8.5 opcache](Do%20not%20rebuild%20bundled%20PHP%208.5%20opcache.md) - On 2026-07-17, docker-php-ext-install opcache failed with "cp: cannot stat modules/*" both in parallel and serial builds.
* [Do not rematerialize magelift destroy after orphan secret delete](Do%20not%20rematerialize%20magelift%20destroy%20after%20orphan%20secret%20delete.md) - After force-clean deletes Magento secrets, a later magelift destroy previews CREATE of Cloud SQL instead of finishing teardown.
* [Docker Bake map matrix exposes primitive values](Docker%20Bake%20map%20matrix%20exposes%20primitive%20values.md) - MageLift docker-bake.hcl used `php.key` and `php.value` for a map matrix, but Buildx exposed each matrix item as the primitive map value.
* [ECS awslogs requires execution role CreateLogStream](ECS%20awslogs%20requires%20execution%20role%20CreateLogStream.md) - Wiring container logConfiguration to /magelift/<project>/<env>/{web,deploy,cron} is insufficient alone.
* [ECS capacity provider names cannot start with aws, ecs, or fargate](ECS%20capacity%20provider%20names%20cannot%20start%20with%20aws%2C%20ecs%2C%20or%20fargate.md) - CreateCapacityProvider rejects names prefixed with aws, ecs, or fargate; project tags like awsap produce invalid names unless rewritten.
* [ECS EC2 capacity requires a pinned ami-* instanceAMI](ECS%20EC2%20capacity%20requires%20a%20pinned%20AMI%20instanceAMI.md) - computeMode ec2-asg fails plan admission with an empty AMI; pin an ECS-optimized ami-* from the public SSM parameter, do not omit instanceAmi.
* [ECS Exec requires service and task-role wiring](ECS%20Exec%20requires%20service%20and%20task-role%20wiring.md) - The CLI ECS Exec path is only valid when the ECS service sets enableExecuteCommand=true and the application task role grants ssmmessages CreateControlChannel/CreateDataChannel/OpenControlChannel/Op...
* [ECS integrated ALB must target varnish container 2026-07-19](ECS%20integrated%20ALB%20must%20target%20varnish%20container%202026-07-19.md) - For applicationMode=integrated, ECS Service LoadBalancers.ContainerName must be varnish (port 6081), not web.
* [ECS Managed Instances cannot combine instanceGenerations with a pinned SKU](ECS%20Managed%20Instances%20cannot%20combine%20instanceGenerations%20with%20a%20pinned%20SKU.md) - CreateCapacityProvider rejects instanceGenerations current/previous together with a generation-specific AllowedInstanceTypes value such as m6i.large.
* [ECS Managed Instances capacity providers bind to the cluster at create](ECS%20Managed%20Instances%20capacity%20providers%20bind%20to%20the%20cluster%20at%20create.md) - CreateCapacityProvider for Managed Instances takes cluster and auto-associates; PutClusterCapacityProviders is unsupported and races before ACTIVE.
