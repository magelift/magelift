# ADR 0002. Report evidence for each tested path

MageLift publishes the configuration and outcome of a test. Tests cover Go resolution, provider graphs under Pulumi mocks, selected SDK calls through Floci, workflows under act, and specific end-to-end runs when available. Cloud services and Magento releases evolve independently. The application owner chooses services and accepts the resulting environment. Historical evidence retains its original dates, scope and wording. [Provider coverage](../capability-matrix.md)
