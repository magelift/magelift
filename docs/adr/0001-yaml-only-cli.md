# ADR 0001. PHP project configuration

MageLift evaluates `magelift.php` with PHP and passes a normalized document to its Go resolver. This lets Magento developers use functions, loops, named SDK objects and shared PHP helpers. The CLI records environment edits in an adjacent PHP companion. The project has never had users of a released YAML format. The importers read the native YAML formats of Adobe Commerce Cloud and Upsun. [Current configuration reference](../configuration.md)
