The current local Compose workflow provides bind-mounted source, pinned MySQL and Valkey, optional OpenSearch and RabbitMQ profiles, reset, logs, and direct exec. It does not yet implement Magento installation seed automation or local HTTPS hostnames. Documentation was corrected to avoid claiming those features until a project-specific seed policy and certificate lifecycle are designed and tested.
