Working name MageLift pending trademark clearance. Apache-2.0 monorepo initially published under GitHub user acourtiol. Primary users are Magento developers. V1 is a local/self-hosted CLI platform for Magento Open Source and Adobe Commerce, production golden path first, AWS-only implementation with multi-cloud interfaces but no second provider. Optimize total cost of ownership for mid-market workloads and Multi-AZ application availability. Headless support means Magento backend outputs/routing/CORS, not deploying storefront frameworks.
