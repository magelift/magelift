# Support

Start with the [MageLift guides](https://magelift.dev/docs/) for installation,
migration, and day-to-day commands.

Open a [GitHub issue](https://github.com/magelift/magelift/issues) if you get
stuck. Include the MageLift version, cloud runtime, command, and the result
you expected. Redact credentials, account identifiers, and customer data.

Use private reporting for vulnerabilities. [Security policy](SECURITY.md)
