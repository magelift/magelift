# Certify MageLift

Use this skill only when the test account, credentials, image digest, and
cleanup owner are known.

## Working rules

- Give every run a unique prefix and use one immutable image digest.
- Preview first. Use the smallest profile that exercises the cell.
- Keep the cell catalog and checkpoint generated by the harness.
- Exercise runtime health and the relevant day-two operation, not only Pulumi.
- Certify only `docs/capability-matrix.md` plus `docs/evidence/` for the exact
  MageLift tuple. Private sibling Magento shops are architecture examples, not
  certification targets and not the only supported AWS shape.
- Destroy on exit and run the provider orphan assertion.
- Record edition, Adobe patch, PHP, provider, runtime, service choices, evidence
  tier, digest, result, and cleanup result.
- Publish **one current proof file** under `docs/evidence/` plus sealed JSONL
  under `docs/evidence/runs/` when the claim is current. Do not append a KEEP
  leftover ledger.

## Do not certify

- A mock-only result.
- A cell that passed with a mutable image tag.
- A result with an unresolved cleanup failure.
- Adobe Commerce without a pullable licensed artifact and Composer credentials.
